# Indian Army Defence Conversation Intelligence

## Run in VS Code

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Files
- `app.py` — Streamlit application
- `Indian_Army_Defence_Conversation_July_August_2026.xlsx` — Excel dataset
- `Indian_Army_Defence_Conversation_July_August_2026.csv` — CSV version
- `indian_army_logo.png` — user-provided logo used in the application

## Important
The July–August 2026 dataset is an academic synthetic/modelled dataset created for this project.
It is not verified official platform analytics.
